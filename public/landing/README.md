# Landing Images

Put the six photos for the opening screen in this folder.

Use these exact filenames:

- `landing-01.jpg`
- `landing-02.jpg`
- `landing-03.jpg`
- `landing-04.jpg`
- `landing-05.jpg`
- `landing-06.jpg`

`landing-01.jpg` is preloaded and appears first, so make that the image you want visitors to see immediately.

For fast startup, export these around 1800px on the long edge instead of using full-size originals.
